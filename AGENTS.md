## Agent skills

### Current design only

This repository is in active development. Implement only the current design
and data format; when interfaces, schemas, or directories change, remove the
superseded implementation, migration path, fallback, and dual entry point.

`docs/agents/issue-tracker.md`.

`docs/agents/triage-labels.md`.
