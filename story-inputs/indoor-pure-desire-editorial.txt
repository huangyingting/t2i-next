BRIEF

创作一批多样、精致、超写实的室内纯欲成人时尚摄影 Theme。所有人物必须是明确、
清醒、自愿且外观成熟的成年人。纯欲风格指柔和、洁净、亲密、含蓄与成熟性感同时
存在：画面可以甜美、轻盈、慵懒、羞涩或挑逗，但不得依赖幼态面孔、少女身份、
学生身份、校服、儿童房、玩偶化比例或任何未成年暗示。

核心视觉身份

每个 Theme 都必须同时保留：

1. 明确的室内空间及可信的家具、材质、尺度、光源和活动边界；
2. 一个具有强烈感官吸引力但人体结构与承重可信的主姿势；
3. 自由设计且与人物、空间、姿势和 content level 相符的服装、服饰、妆容、打扮与发型；
4. 柔和纯净与成熟性感之间的纯欲张力；
5. 高预算成人时尚杂志、私密生活方式广告或精致 beauty editorial 的摄影完成度。

室内场景

所有场景必须位于真实、封闭、可进入且可安全退出的室内。可使用私人卧室、酒店套房、
衣帽间、梳妆室、起居室、阁楼、公寓、摄影棚卧室布景、室内休息室、私人化妆间、
室内温室休息区、书房、音乐室、宽敞浴室、干燥更衣区、室内泳池休息区、封闭阳光房
或其他功能明确的私人室内空间。不得把露台、屋顶、庭院、海滩、街道、森林、田野、
车辆外部或开放公共空间写成室内。

每个 Frame 清楚写出至少四项空间证据：墙面或窗框、地面、床或家具、门或空间边界、
窗帘、灯具、地毯、镜面、软垫、床品、台面、室内植物、收纳结构或天花。背景必须
服务人物和姿势，不得退化为空白房间、廉价直播间、偷拍卧室、监控画面或普通自拍。

纯欲风格锁

纯欲不是幼态，也不是只使用白色内衣。每个 Theme 从以下关系中选择两至四项并重新
组合：柔和自然光与局部暖灯、洁净皮肤与真实毛孔、松弛服装与精致配饰、浅色空间与
深色造型、羞涩眼神与主动姿势、含蓄表情与开放身体线条、日常材质与高级剪裁、
慵懒发丝与完成度高的妆容、柔软织物与清晰骨骼轮廓。

整体质感可以明亮高调、奶油柔光、晨光薄雾、暖金床头灯、低饱和胶片、冷白月光、
粉棕卧室、深色奢华、清透日系、韩系光泽美妆、法式慵懒或现代极简，但不得连续生成
相同的白色床、白色吊带、黑色长发、裸粉唇和正面仰卧。

人物与造型自由度

服装、服饰、妆容、打扮和发型均为自由变化轴。每个 Theme 先建立完整人物造型档案：
精确成年年龄、体型、身高体态、脸型、五官、肤色、皮肤纹理、发长、发型、发色、
妆容、服装类别、穿着状态、材质、主辅色、鞋履与零至四件配饰。相邻 Theme 至少改变
人物造型、姿势家族、室内空间、服装轮廓、主色、发型和妆容中的五项。

服装可自由选择吊带裙、衬衫、针织上衣、开衫、短款上衣、抹胸、背心、睡袍、晨袍、
衬裙、丝质睡衣、蕾丝内衣、胸衣、短裙、开衩裙、短裤、长袜、连裤袜、薄纱罩衫、
男友风衬衫、贴身连衣裙、宽松针织、结构化时装、皮革、丝绸、缎面、蕾丝、薄纱、
棉、麻、羊绒、天鹅绒或其他合理室内造型。颜色覆盖象牙、奶油、裸粉、蜜桃、珊瑚、
猩红、酒红、焦糖、橄榄、祖母绿、青绿、天蓝、海军蓝、薰衣草、梅紫、银灰、
石墨、黑色与印花，不把纯欲固定为白色。

服装状态可完整穿着、松弛垂落、单侧滑肩、解开部分纽扣、卷起衣摆、半披外套、
透明叠层、湿润贴合、轻微褶皱或根据 content level 合理半褪。必须写清每件服装实际
停留位置、材质反应和与姿势的关系，不得让服装悬浮、穿透身体或遮住关键承重点。

配饰可自由选择眼镜、耳饰、项链、丝巾、发带、发夹、手套、腕表、臂环、腰链、
腿环、脚链、袜带或室内鞋履。鞋履可为赤脚、拖鞋、细带高跟鞋、玛丽珍鞋、乐福鞋、
短靴或长靴，但必须适合地面、家具和姿势，床面姿势默认赤脚或柔软袜类。

发型从精灵短发、波波头、齐肩发、长直发、大波浪、自然卷、松散盘发、高低马尾、
辫发、湿发背梳、凌乱睡醒发、侧分、齐刘海、空气刘海或无刘海中自由变化；发色可为
自然黑、深棕、栗色、铜色、酒红、蜂蜜金、铂金、银灰、挑染或渐变。头发必须服从
重力、枕面压痕、肩颈接触和动作方向。

妆容可为清透裸妆、奶油底妆、光泽底妆、柔雾底妆、粉棕眼妆、蜜桃眼妆、烟熏眼妆、
图形眼线、湿润眼睑、晒伤腮红、低饱和修容、雀斑妆、渐变唇、玻璃唇、哑光唇或
近乎无妆。每个 Theme 至少明确眉形、眼妆、腮红位置、唇色质感与一项皮肤细节。

表情与感官张力

表情在含羞回避、主动凝视、半睁湿润眼神、轻咬下唇、若有所思、呼吸微乱、闭眼沉浸、
回头挑逗、克制微笑、惊讶张唇、自信控制、慵懒困倦或情绪释放之间轮换。每个 Frame
至少描写眉形、眼睑、瞳孔方向、嘴唇、脸颊张力、下巴或头部角度中的四项。表情必须
来自人物主动情绪，不得表现恐惧、疼痛、失去意识、胁迫或无法退出。

姿势选择与相机

同一批次在仰卧、侧卧、俯卧、四点跪姿、直立跪姿、深蹲、坐姿和站姿之间轮换。
相邻 Theme 不得重复姿势家族、双腿关系、主要承重点、头部方向和相机方位。模型不得
只反复生成仰卧宽腿、四点跪姿或扶墙前倾。

构图与视角锁

每个 Theme 必须明确写出相机绕人物的方位、相机高度、俯仰角、拍摄距离、焦段、
裁切尺度和人物在画面中的落点，不能只写 cinematic angle 或 flattering view。
视角从以下家族中轮换：

- front view 正面：相机位于人物正前方约 0–15 度，强调眼神、胸腹、双腿关系和
  正面姿势几何；
- side view 纯侧面：相机位于人物左侧或右侧约 80–100 度，强调额头、鼻尖、下巴、
  胸部、腰背、臀部和腿部构成的连续侧面轮廓；
- rear view 正后方：相机位于人物背后约 165–195 度，强调肩胛、脊柱、腰臀和后侧
  腿部线条；人物必须回头、转为可读侧脸或借可信镜面显示表情；
- front three-quarter 前侧三分之四：相机位于左前或右前约 25–65 度，同时显示
  面部、躯干纵深、腿部关系和服装层次；
- rear three-quarter 后侧三分之四：相机位于左后或右后约 115–155 度，同时显示
  回眸表情、背部、臀腰曲线和承重点；
- overhead/top-down 顶视：相机位于人物上方约 70–90 度俯拍，强调床品、四肢、
  衣料和家具形成的平面图形；
- elevated oblique 高位斜拍：相机位于人物上方约 25–65 度，显示姿势、承载面、
  室内纵深与人物落点；
- eye-level 平视：相机接近人物脸部、胸部、腰部或坐姿高度，强调亲密交流和自然比例；
- low-angle 低机位：相机位于床垫、地板、椅面或膝盖高度向上拍摄，强化腿部、
  身体张力和室内高度，但不能造成窥视感或遮住脸；
- beauty/action detail 近景：使用 85–105mm 聚焦面部、美妆、手部、衣料或动作细节，
  同时保留足够肩颈、躯干或环境锚点，不能裁成无法归属的身体碎片。

相机滚转、观察位置与特殊构图可叠加到上述视角家族，但不能取代准确人物方位：

- Dutch angle/canted angle 荷兰角：相机绕镜头轴有意倾斜约 5–20 度，让门框、床沿、
  镜面或身体主轴形成紧张对角线；不得超过约 25 度，不得造成房间倒塌感、眩晕感或
  被误读为拍摄失误；
- over-the-shoulder 肩后视角：从人物一侧肩膀、发丝或上臂后方观察脸部、镜中表情、
  手部或姿势纵深，前景肩部只能作为柔和框景，不得遮住主体；
- head-side/foot-side axial 头侧或脚侧轴线视角：沿床、沙发、长椅或地毯的长轴拍摄，
  利用家具边缘和双腿形成消失点，但避免脚掌或膝盖被广角异常放大；
- floor-reflection 地面反射构图：利用抛光木地板、石材、镜面台或浅色亮面家具形成
  单一可信倒影，倒影服从透视且不生成第二个人物；
- mirror-within-frame 镜中框构图：真实人物占主画面，镜面补充正脸、背部或服装细节，
  不使用无限复制、互相矛盾的姿势或镜像错误；
- foreground veil 前景柔性遮幅：使用半透明窗帘、发丝、丝巾、床幔、门框边缘或失焦
  植物形成层次，遮幅不超过主体关键轮廓且不得产生偷拍或偷窥感；
- environmental wide portrait 室内环境广景：以 35–45mm 展示人物与完整房间几何，
  人物占画面约 35–55%，空间不能喧宾夺主；
- telephoto compression 长焦压缩：以 85–105mm 压缩床幔、灯具、人物和镜面之间的
  层次，突出表情与材质，避免把身体压扁成无纵深平面；
- profile silhouette 侧面轮廓剪影：以窗帘、床头灯或门缝光勾勒鼻唇、肩颈、腰背和
  腿部轮廓，同时用补光保留眼神、妆容和衣料纹理，不得变成无细节黑影；
- centered vanishing-point 中央消失点：让床沿、地板拼缝、墙板或窗框向人物汇聚，
  可结合严格正面或正后方构图，但人物姿势不得机械僵直；
- high-low layered composition 高低层构图：通过床面、地面、椅面、台面和站立高度
  建立前中后景，不通过复制人物或拼贴制造层次；
- cropped editorial tension 编辑式裁切：可在头顶、手肘、膝下或衣摆边缘进行有意
  裁切，但关节不能在视觉上断裂，人物身份、表情和主姿势仍必须可读。

构图在正中对称、偏心三分法、对角线、S 曲线、X 形、C 形、三角构图、前中后景三层、
门框或窗帘形成的 frame-within-frame、镜面双层、床角放射、大片负空间和紧凑满幅之间
轮换。人物可占画面约 35–90%；全身、四分之三身、半身、近景和细节裁切必须服从姿势
和室内空间，不得连续使用人物居中、完整全身、50mm 平视的同一安全构图。

十个 Theme 的批次必须至少各出现一次 front view、side view、rear view、
front three-quarter、rear three-quarter、overhead/top-down 和 low-angle，并同时
覆盖左右两侧、床头或头侧、床尾或脚侧以及房间对角线方位；任一视角家族最多出现
两次。十个 Theme 还必须至少包含一次 Dutch angle、over-the-shoulder、floor-reflection
或 mirror-within-frame、environmental wide portrait、telephoto compression 和
centered vanishing-point；这些技法可与基础视角重叠。少于十个 Theme 时，在请求数量
内最大化不同视角和构图技法，不为凑配额牺牲人体结构、表情或动作可见性。

焦段使用 35–105mm 等效直线投影：35–45mm 用于室内环境与全身，50–70mm 用于自然
人体比例和三分之四身，85–105mm 用于 beauty、材质和动作近景。避免鱼眼、窥视孔、
夸张广角巨头、异常短躯干或无法追踪的肢体。每个 Frame 必须同时看清脸部表情、
主要姿势轮廓和至少两个承重点；正后方构图通过回眸或镜面满足表情可见性。

人体与接触

每只手、脚、膝、前臂、肩背、臀部或骨盆只能承担一个相容任务。床垫、枕头、地毯、
椅面和衣料必须显示可信压陷、褶皱、拉力或摩擦。禁止复制肢体、多余手指、融合身体、
断裂关节、反向膝盖、不可能骨盆旋转、悬浮头发、穿透家具或无法承重的脚尖姿势。

CONTENT LEVEL

准确遵循运行请求的 content level，不得自行提升或降低：

- Aesthetic：完整时尚造型覆盖乳头、外部生殖器、阴毛和肛门。通过姿势、衣料轮廓、

  一件透明、半透明、敞开、滑肩、卷起或半褪下的时尚单品。允许自愿的外部触碰和

  成年露骨行为。主要动作、接触点和参与人物必须清楚可见；不得用裸体、张腿或表情
  代替所需动作，也不得让露骨行为吞没服装、发型、妆容与空间设计。

THEME CONTRACT

每个 Theme 定义一套独立完整的摄影方案：准确运行人数、每位成年人物的稳定身份、
具体室内地点、主姿势或姿势关系、服装与穿着状态、发型妆容、表情、相机方位、
焦段、主光、色彩和材质主轴。运行请求的人数是精确人数，不是上限；不得漏掉人物、
增加伴侣、加入背景路人、用镜中复制制造额外人物或只显示无法归属的身体碎片。

FRAME CONTRACT

同一 Theme 的多个 Frame 是共享人物与造型前提下可独立成立的摄影方案，不是按时间
推进的故事。每个 Frame 必须完整重述人物、室内空间、姿势、服装状态、发型妆容、
表情、承重点、相机和光线，不能依赖上一帧。可在相邻 Frame 改变姿势、视点或家具
关系，但人物身份、content level 和造型主轴保持一致。

VARIATION AND REJECTION RULES

出现以下任一情况就重写：

1. 场景实际位于室外、半开放公共空间或无法证明是室内；
2. 纯欲被写成幼态、学生、少女、校服、儿童房、玩偶或未成年暗示；
3. 整批重复白床、白色吊带、黑色长发、裸粉妆、同一体型和仰卧宽腿；
4. 服装、配饰、妆容或发型只有 generic 标签，没有颜色、材质、结构与可见位置；
5. 姿势超过自然柔韧范围、缺乏支撑、遮住面部、身体结构错误或与家具冲突；
6. 人物数量、性别或 content level 与运行请求不一致；
7. 相邻 Theme 只改变颜色或手的位置，却重复同一姿势家族、相机方位、机位高度、
   焦段、裁切和人物落点；十个 Theme 没有覆盖正面、侧面、正后方、前后三分之四、
   顶视、低机位、荷兰角、肩后、反射、环境广景与长焦压缩；
8. 画面退化为自拍、webcam、CCTV、偷拍、廉价直播、临床检查或普通色情截图；
9. 输出出现规则解释、姿势编号、备选方案、字幕、Logo、水印或可读品牌。

OUTPUT

每个最终 Frame 输出为请求语言的一段自然、连续、可直接用于图像生成的摄影描述。
第一句直接进入具体室内空间、人物或相机视点，不输出标题、Theme 编号、Frame 编号、
姿势编号、规则、清单或自检过程。正文依次自然包含准确人物、成熟外观、室内证据、
主姿势、承重点、服装与配饰、发型、妆容、表情、相机、光线、材质与调色。不要解释
选择了哪个建议姿势；只描述最终画面。
