BRIEF

成人小人国，仅用于 Erotic 和 Hardcore。

角色

female_count 和 male_count 只约束微型人物。每帧画面总人数严格等于 1 + female_count + male_count：一名巨大人物加指定微型人物，不得出现额外脸、头、躯干、肢体或局部人物。系统为唯一巨大人物自动选择成年男人或成年女人；该 Theme 全部 Frame 固定此选择。
所有人物均为自愿互动的多元东亚成年人。巨大人物是环境尺度主体；双方均可发起、回应或引导，Theme 锁定发起方。

小人国世界

每个 Theme 位于专为掌心成年居民建造的室内小人国。微型人物是真实成年原住民，拥有自然成人比例、皮肤和五官；唯一巨大人物是正常人类世界的成年访客，身体与器官保持普通成人尺寸。除总人数和镜头焦距外，不得输出比例、人物或物体尺寸、长度单位、preset、profile 或 configuration。
每个 Frame 分开描述：先写微型原住民人数、性别和身份，再写正常人类访客性别、身体与压倒环境的体量。始终使用“living miniature adult woman/man native”与“normal-human-sized giant visitor”，不得把双方简称为同尺寸普通人物。
所有微型人物使用完全相同的头身比、肩宽尺度和四肢长度；只能用脸、发型、服装和颜色区分身份，不得用高矮、娇小、修长或不同骨架区分。需要比较体型时，把全部微型人物安排在相同或相近的相机距离，不得让其中一人单独靠近镜头。
用身体锚点强制可见比例：同一景深内，每名微型人物的完整身高短于巨大人物手腕至中指尖，能站在其掌心，头部小于其拇指末节。每帧至少一名微型人物与巨大手、脚或脸无遮挡并排；插入者仅露上身时，用握持它的巨大手作对照。所有微型人物投影身高相等，绝不能因镜头距离呈现为普通成人大小。
小人国门框匹配居民身高，床、台面、车辆和家具只供居民使用；巨大访客手大于门洞、身体跨越多个房间。单件小人国家具不能承托访客全身，须由地面、墙体或多组结构支撑。环境与身体共同证明差异。仅保留参与动作的容器或工具。

单一身体与单一性器官

每个 Frame 只允许一具解剖连续的巨大成人身体，并只允许一个目标性器官可见。巨大男性只能有一根与同一骨盆连续连接的阴茎；巨大女性只能有一个与同一骨盆连续连接、结构统一的阴道口或肛门作为目标。目标器官在一个专门句子中只命名一次；该句必须描述它相对微型人物的巨大尺度、朝向、自然表面、根部或周围组织与骨盆的连续连接，以及当前接触造成的可见压力或形变。器官内部结构词只能作为这个单一器官的组成部分出现；后文统一称“the contact point”。
目标器官保持普通成年人自然尺寸，只因掌心小人而显得巨大，不得放大成洞穴、房间或建筑。根据当前目标只选一个互斥模板：penis 保持自然 shaft、glans 与根部；vaginal opening 保持连续外部褶皱与入口；anus 保持自然放射褶皱与入口。微型人物从头到脚始终完整位于巨大访客体外；组织只能在唯一外部接触点受压变形，任何头、躯干、骨盆、手臂、腿或脚都不得进入体内。
每个人保持一条独立闭合的头—颈—躯干—骨盆—四肢链，拥有自己的头、胸廓、骨盆和四肢。除唯一接触点外，人物轮廓不重叠、不融合、不共享肢体；多个微型人物的头和躯干之间保留可见背景空隙，并处于不同空间槽位和支撑面。微型人物性器官被服装遮住或位于画外。
画面必须显示目标部位到所属胸廓或骨盆，再到巨大人物躯干或大腿的连续轮廓；不得用裁切、道具或失焦切断这条连接。
巨大人物可以完整出现，也可以只出现与主要互动相关的局部身体。局部构图必须同时保留目标部位、所属胸廓或骨盆，以及至少一段相连的躯干、臀部或大腿，以证明器官归属和巨大尺度；裁切只能发生在画框边缘的自然身体延伸处，不得切过关节、骨盆或接触点。

互动

Erotic 和 Hardcore 中，全部性行为或性活动只发生在一名或多名微型人物与唯一巨大人物之间，且已有直接接触。禁止微型人物彼此、巨大人物独自或第三方性活动。每名微型人物须直接接触巨大人物，或操作由工具、支撑或体液轨迹连接巨大人物的同一动作链；不得旁观或另开动作。每帧只有一个连续主要行为、目标器官和接触中心。微型人物、巨大人物或双方均可发起；须明确发起与回应，并在同一接触中心闭合。
巨大人物主动时，除唯一接触点外，每个 Frame 只用一只手或一件工具完成一个动作；也可不用手，让唯一接触点主动贴近微型人物。其他参与者各自只承担一个回应、支撑、操纵工具或承接任务，不得制造第二组性动作。巨大手指不得遮住微型人物头部、躯干或主要接触。
非常规活动必须把巨大体型反差转化为一个可见、可拍摄且物理成立的性机制。可从触碰、摩擦、亲吻、舔舐、吸吮、口交、外部身体工具、成人玩具、恋物接触，或由手、口、身体、服装、家具和环境产生的刺激中选择；每个 Frame 只选一个主要行为，并让所有参与者围绕同一接触中心形成一条动作链。

可以使用成人之间明确自愿的暴露、窥视角色扮演、羞辱、物化或宠物化情境，也可采用带窥视感的环境机位；但每个人仍须表现出可辨认的发起、同意或回应，不得把人物写成没有身份、姿势与意志的孤立身体部件。此类主题仍须遵守非微距、完整空间和单一身体规则。

每帧必须让微型身体或工具压住唯一接触点并造成可见形变。approaching、within reach、alignment、readiness、waiting、traverse toward、approach 等准备词无效；画外行为、纯观看、纯展示或姿势暗示也不满足。

内容级别

Erotic：允许艺术裸体、一个可见目标器官与明确但非插入式的微型—巨大直接亲密接触。
Hardcore：主要露骨行为必须直接发生在微型人物和巨大人物之间，可包含口交、直接生殖器刺激、成人玩具和体液互动；不得把多个行为堆在同一 Frame。

Hardcore 标志性机制

每个 Theme 先锁定一个 Signature Mechanism：一件有名称的装置或小人国设施、一个操作者、一个目标和一个正在发生的可见效果。互动若可概括为拥抱、依偎、坐在腿上、并排摆姿、仅用手抱住或无装置触碰，必须重写。
- 空中探险：软绳、安全带、滑轮、绞盘、脚手架或悬桥已把一人悬吊在接触点并持续摩擦，另一人控制承重。
- 流体工程：一人持续刺激，另一人用杯、浅碗、漏斗、雨伞、导流槽或微型蓄水结构承接同一来源的喷射。
- 重型机械：小人国叉车、起重机、升降台、传送带或轨道车通过软垫托架把正常人类尺寸成人玩具压在接触点，一人操作、一人校准。
- 巨人发起：巨大访客用一只手把完整可见的微型人物作为外部身体工具，另一人稳定手腕或建立牵引；所有身体保持分离。
生成两个或更多 Theme 时，至少一个用重型机械、一个用非机械机制；三个或更多时，前三个分别使用重型机械、流体工程和空中探险；四个或更多时再加入巨人发起。新 Theme 不得重复机制家族、装置、房间或支撑面。装置必须占据清楚画面空间并把每名微型人物连接到同一接触点。

人体与物理

每名微型人物只写一个稳定姿势、一个主要支撑和一个任务。肩—肘—腕—手与髋—膝—踝—脚必须连续自然；两臂两腿归属清楚，重心落在可见支撑面。不要逐根数手指、罗列精确关节角度或让肢体正对镜头。
攀爬者保持三个可见接触点。人物、绳索、工具和机械不得悬浮、穿透或融合。
体液必须来自唯一可见接触点，沿连续且符合重力的轨迹到达明确落点，并留下比例合理的液面、飞溅或湿痕。不得出现无来源液体或不成比例的洪水。
机械必须完整接地并显示轮子、承重托架、操作者和负载之间的连接；一件工具只承担一个任务，不得遮挡主要接触或制造额外器官轮廓。

人物造型

微型人物采用夸张、舞台化、从头到脚完整设计的高级时装造型，不得出现未经设计的普通便服。每人固定一个强烈轮廓特征，例如雕塑感肩部、几何披风、夸张褶边、宽大裙撑、收束腰线或厚底鞋；再固定一个醒目发型、头饰或超大配饰。不同微型人物的轮廓与强调色必须一眼可区分，并在同一 Theme 的全部 Frame 保持一致。
Erotic 和 Hardcore 中，巨大人物每个 Theme 可选择裸体或部分穿着，并在全部 Frame 保持一致。部分穿着可保留一至两件衣物及一件配饰，但骨盆、目标部位及其与胸腹、臀部或大腿的连续关系必须清楚裸露；衣物不得覆盖接触点、伪装成肢体或制造额外身体轮廓。
夸张造型不能改变人物身高、头身比、肩宽、四肢长度或骨架。微型服装按小人国居民的共同尺寸裁制；不得用更大的帽子、裙摆或鞋底误判人物实际高度。
优先使用 glossy satin、velvet、metallic fabric、transparent organza、patent leather 与 embroidery 形成强对比。Frame 中每名微型人物的造型描述使用 25–40 个英文单词，可写两种颜色、两种主材质、一个轮廓特征和一个配饰；巨大人物只用 15–25 词按 Theme 选择描述裸体或部分服装、发型与配饰。服装、长发和配饰不得复制成额外肢体，不得遮住脸、手、承重点、身体连接或唯一接触中心。
人物表情必须生动、具体并与发起或回应角色一致。每个 Frame 分别为发起者和回应者指定一个简短表情；不得让所有人共享相同的空洞、微笑或惊讶表情。每个 Theme 至少一个环境中景或全景必须显示发起者和回应者的脸与不同表情。
Erotic 可表现期待、羞涩、挑逗、惊喜或沉浸；Hardcore 可表现极度性兴奋、失神快感或高潮临近，通过灼热眼神、收紧或扬起的眉眼、潮红面颊、张开的嘴唇、急促呼吸和可见肌肉张力表达。表情必须保留自然面部结构，不得出现翻白眼、扭曲嘴部、异常舌头、重复五官或暗示非自愿的恐惧痛苦。
每人的表情描述使用 15–25 个英文单词。远景用清楚的头部朝向、身体张力和轮廓光传达表情关系；中景呈现可辨认的眉眼与嘴部。不得为了显示表情而放大微型人物、放大头部或改用贴脸特写。

场景美术

不写导演姓名或模仿在世创作者。采用原创形式主义电影美术：正面中心构图、精确轴线、舞台化室内、手工质感、冷面幽默与克制奇趣。
受控色板选自灰粉、芥末黄、湖蓝、薄荷绿、奶油白与酒红；每场三种主色与一种强调色。家具、门框、壁纸和灯具采用整齐网格、成对排列、重复几何与明确留白。
对称只用于建筑、家具、灯光和道具，不得镜像、复制或成对增加人物、乳房、骨盆、肢体或性器官。人物和唯一接触点可以轻微偏离中轴，以保持单一身体与清楚动作。用门框套景、连续房间、地板线、家具层次和色块分区建立纵深，不能让形式化构图压平成无空间感的平面。
每个 Frame 最多描述两个建筑特征和三个场景颜色，不得罗列墙面、地板、灯具、家具与装饰的完整清单。所有墙面、地板、家具和道具采用哑光、不反射、不透明表面，保持单一真实空间。

镜头

禁止微距摄影、微距镜头、极端特写以及贴着皮肤或微型人物拍摄。强制使用 20–32 mm 等效广角，保留明显但可信的近大远小、汇聚线和前后景拉伸；可移轴让不同距离主体清晰，但不得消除透视变形或制造假缩微滤镜。禁止鱼眼、正交感、平视平拍、极端透视缩短和奶油散景。
每个 Theme 至少一个 Frame 明确使用 room-scale wide establishing shot；只有一个 Frame 时必须使用该景别。镜头必须二选一：贴近微型人物支撑面的低机位仰拍，让巨大访客向上占据画面并压过小人国建筑；或从巨大访客肩部以上向下的高机位俯拍，让完整微型人物、装置和房间层级缩入其身体周围。不得使用平直眼平视角。
从房间角落、门口或家具外侧斜拍，展示空间边界、巨大人物完整身体或大段连续身体及全部微型人物。低机位把巨大身体置于近景，高机位以巨大身体边缘构成近景框架；微型人物保持同一相机距离，以对角线连接前景巨大身体、中景互动和背景边界。
其余 Frame 在 low-angle wide full shot、high-angle oblique full shot 或 partial-body wide environmental shot 中轮换。局部身体镜头可以让巨大人物超出画框，但必须保留目标部位到胸廓或骨盆及相邻躯干、臀部或大腿的连续路径。多 Frame 不得连续使用相同高度、方向和景别；两个以上 Theme 必须同时覆盖一次仰拍和一次俯拍。
所有景别保持前景空间锚点、中景互动和背景房间边界三层深度。微型人物、唯一接触点、巨大身体归属和至少两条强烈汇聚的房间深度线同时可辨。使用中等至较深景深，禁止用虚化隐藏空间。
只保留主动作必需的一个工具和一个主光方向，不得添加任何不参与主动作的松散小物。

Theme 与 Frame

Theme premise 必须简短写明：小人国场景；微型原住民人数和性别；访客性别；发起方与回应方；唯一目标；Signature Mechanism 的装置、操作者和可见效果。
同一 Theme 的多个 Frame 是同一个已经发生的主要行为在不同机位下的独立重演，不是前后发展的连续故事。每帧开场时直接处于接触之中；禁止接近、准备、开始攀爬、驶向、下降前往、等待或即将发生。
每个 Frame 硬性至少 700 个英文单词并组成单一段落。返回前实际计算词数；不足 700 词时继续补充可见细节。

4. 为每名微型人物分别使用 90–120 词，描述其位置、一个姿势、一个支撑、一个任务以及与其他人物相同的固定身高。

只用自然英文和简单现在时。禁止“previous frame”“as before”“still”“again”“now”“remains”“has moved”“has advanced”等跨帧词；“same”和“identical”仅说明共同尺度。每个分句只写画面中存在的肯定事实。返回前最后执行：第三句起把 penis、vaginal opening、anus 替换为 the contact point；翻译中文；删除 no、not、without、unseen、uninvolved 片段；把 centimeter、inch、twentieth、pencil 改成无数字正面描述；首句逐字保留英文锚点。结尾停在主光方向，不附自检报告。
