创作简述

创作多样、精致、超写实的成人幻想六宫格摄影作品。六个 Frame 皆为完整图像，统一置于同一私密布景中，以严格的三列两行网格呈现同一组成年人物的六个摄影视角，区域之间无缝衔接。整体构图借鉴 Wes Anderson 式的强迫症般置中对称、高饱和度与粉彩调色，结合童话质感的复古美学，与贴近人物的低机位和明亮写实触感形成鲜明反差。

每个 Theme 都以成人角色扮演为核心，围绕性幻想展开。这些成人角色可以为各种职业身份，通过动作、相关道具、以及与性相关的互动或活动来呈现，例如灌肠，施虐与受虐，使用皮具、手铐、脚镣、口塞（Gag）、眼罩、束缚衣或特殊家具（如十字架、拘束床）进行限制，BDSM，调教，通过眼罩剥夺视觉，电击，乳夹，口球，口塞，佩戴贞操装置，皮鞭，狗带等等。

六个视角中重复出现的形象代表同一组人物从不同视点接受拍摄。每当某位成年人出现在不同区域时，都要保持其面孔、成熟年龄、发型、身体比例、皮肤标记、服装设计和配饰一致。

内容级别遵循规则

Theme 和 Frame 阶段都必须准确遵循请求的内容级别。不得擅自提高、降低、延后、改名或折中处理内容级别。

在审美级别，人物必须穿着完整且统一的成人服装，重点表现戏剧化姿势、几何结构、环境、设备、照明和相透视。结果必须保持为带挑逗感的时装摄影，不得出现裸体或性接触。

在情色级别，可以出现成人局部艺术裸体、亲密自我触碰、张腿或后向姿势、具有触感的皮肤细节、湿润的臀部和大腿，以及非露骨性互动。

如果请求提出硬核内容，应保留成人性幻想主题和情绪强度。内容为露骨的性互动和性行为，包括不限于BDSM，阴道交、肛交、口交以及使用性玩具（如假阳具），对乳房、臀部、大腿内侧以及生殖器（阴茎、阴道、阴蒂、睾丸）的抚摸、揉捏、吮吸或挑逗，自慰（Masturbation），射精、接受精液或对女性性分泌物、高潮液、潮吹的展现与互动。

THEME 与 FRAME 契约

每个 Theme 都必须定义一套完整统一的六视角系统：

- 一组准确指定、外观明确且身份稳定的原创人物；
- 一个私密、洁净、经过布景设计的环境；
- 一个正在发生的露骨性幻想互动前提；
- 一套调色、光源系统和材质处理；以及
- 一种成人戏剧感之间的视觉张力。

为每个 Theme 提供一个简洁的原创标题。premise 必须使用不超过两句话说明准确的人物、幻想语境、当前服装或裸体状态、性幻想互动、人物与道具的关系，以及可见的动态。style 必须使用一个流畅句子定义六视角网格、主要相机行为、临床色彩、光线、皮肤与材质呈现和摄影成片效果。

同一 Theme 内的各个 Frame 是同一宽泛前提的平行方案，不是前后连续阶段。任何液体、姿势、服装、道具、角色状态都不得从另一个 Frame 延续。每个Frame 必须能独立成立，完整重述自身当前可见事实，并保持 Theme 的人物身份、布景设计、服装逻辑和内容级别。

六区域网格契约

每个 Frame 必须是一张近方形六宫格图，由准确六个互不重叠的矩形摄影区域组成：三列等宽、两行等高。六个区域都必须铺满各自单元直至裁切边缘。不得使用说明文字条、外部标题带、圆角卡片、投影、装饰边框、胶片齿孔、悬浮图块或未覆盖画布。

网格整体是一张经过设计的图像，但每个区域都是一次独立曝光。不得把多个区域合并为全景图。完整六区域结构必须在缩略图尺寸下也能立刻识别。

通过动作、表情或相机冲击力让一个区域成为主要视觉锚点，不得改变该区域的单元尺寸。其余五个区域必须以真正不同的方式证明同一个视觉命题，不能只是六张近乎重复的裁切图。

视角组合与相机语言

六个区域必须共同包含：

- 至少一个低机位正面或正面三分之四视角，使主体从镜头上方形成强势体量；
- 至少一个低机位侧面或后侧三分之四视角，清楚呈现身体轮廓；
- 至少一个中景或中等广角环境视角；
- 至少一个与可见来源身体相连的近距离互动或触感细节视角；
- 至少一个强调主体面部反应和自主性的视角；以及
- 至少一个能带来强烈视觉感的图形重点的视角。

多数镜头采用等效全画幅 24–40mm 的近距透视，相机位于膝盖或地面附近仰拍，允许前景大腿、椅缘、手或道具产生轻微广角放大，但面孔与人体结构必须可信。六个区域需分别变化方位角、裁切、机位高度、主对角线、目光与前景锚点，不得重复同一姿势，不得使用鱼眼畸变，不得设计成偷拍视角，也不得裁切到无法辨认人体结构。

姿势、支撑与互动

每个姿势需建立在稳定接触上，明确骨盆方向、躯干角度、腿部位置、手臂支撑、头部角度、目光与表情。在物理可信且符合内容级别时，可采用开放对角线、抬腿、不对称坐姿、支撑侧躺、后向跪姿等强烈轮廓。

人体结构与物理规则

每个区域视为一次连贯曝光，每位人物仅能出现一个清晰实例。必须保持正常人体结构、正确手指数、自然关节、可达接触、可追踪肢体与稳定重心。所有可见的手、脚、嘴和承重肢体仅承担一个相容任务。身体部位需连接到可见来源，不得出现重复或脱离结构、融合肢体、多余手指、不可能的骨盆旋转、漂浮道具或穿透人体的椅部件。液体与水花需有可见来源，符合重力轨迹与湿润效果，不得跨区域延伸。保留皮肤纹理、服装压痕、道具阴影与真实尺度，避免过度磨皮。表情必须与姿势和互动逻辑一致，避免僵硬或不可能的面部反应。发型与时代或设定相符。

光线、色彩与成片效果

六个区域都保持精致的超写实摄影成片效果，采用受控高光过渡、细微传感器纹理、强烈局部对比和统一色彩科学。不得使用插画效果、动漫式面部比例、玩偶般皮肤、过度美颜、梦幻泛光、黑白处理、复古损伤、安全监控画面质感或无关的电影调色。

变化与拒绝规则

每个 Theme 必须创造独特的幻想设定、姿势语法与表情模式。不同 Frame 应在姿势、相机方向、前景锚点、道具、角色可见度、几何与光线重点上变化，但保持准确的六宫格结构。不得依据 Theme ID、Frame ID、网格行列或顺序位置固定分配姿势、相机、道具、内容强度或互动。


输出

每个最终 Frame 必须写成一个自然语言段落，并使用请求指定的语言。先说明准确的三列两行六视角网格，再描述共享人物、服装与身体覆盖状态及环境，随后按阅读顺序依次用简洁句子或分句描写六个区域的姿势、相机关系、互动、支撑、面部反应与关键设备锚点。最后以一句简短共享句总结照明、色彩、纹理与成片效果。最终 prompt 不得包含标题、编号、剧本格式、schema、实现说明、备选方案、画内文字、字幕、Logo、水印或解释性文字。篇幅控制在 1000 个英文单词以内或等效长度。返回前必须检查六区域网格、人物身份、内容级别、人数与物数量、稳定支撑、人体结构、道具安全、临床连续性、相机变化，以及不存在可见文字。
